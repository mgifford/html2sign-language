# Upstream provenance and maintainers

This starter includes no third-party source code, weights, pose recordings or dictionary exports. The following works are credited as research/reference dependencies, not presented as implemented in P0.

| Resource | People/maintainers | Role and licence to verify |
| --- | --- | --- |
| [3D-LEX / SAPA](https://github.com/OlineRanum/SAPA) | Oline Ranum, Gomèr Otterspeer, Jari I. Andersen, Robert G. Belleman, Floris Roelofsen | 2024 3D lexicon; code MIT and dataset CC BY 4.0 per published descriptions; access and terms per asset need verification |
| [Spoken-to-Signed Translation](https://github.com/sign-language-processing/spoken-to-signed-translation) | Sign Language Processing contributors; cite repository's CITATION and [research paper](https://arxiv.org/abs/2305.17714) | Planned ASL lexical adapter; confirm exact commit and code/data licences before integration |
| [ASL-LEX](https://asl-lex.org/download.html) | ASL-LEX research team, cite 2017 and 2021 papers | Lexical metadata: the download page says CC BY 4.0 in its text but its footer says CC BY-NC 4.0; treat the terms as unresolved until confirmed. Reference videos are separately copyrighted. |
| [Sign Language Translator](https://github.com/sign-language-translator/sign-language-translator) | Sign Language Translator contributors | Alternative mapping framework, Apache-2.0 project licence; not used yet |
| [Mozilla Readability](https://github.com/mozilla/readability) | Mozilla contributors | Future structured article extraction (Apache-2.0), not included in P0 |
| [DOMPurify](https://github.com/cure53/DOMPurify) | DOMPurify contributors | Future sanitization, not included in P0; inert parsing now |
| [Transformers.js](https://github.com/huggingface/transformers.js) | Hugging Face and contributors | Future pinned browser inference, not included |
| [WebLLM](https://github.com/mlc-ai/web-llm) | MLC contributors | Optional comparison inference runtime, not included |
| [Three.js](https://threejs.org/) | Three.js contributors | Existing main repo renderer; not used by this starter |

Contribute fixes upstream when maintainers welcome them. Keep a record of issues and PRs offered, plus citation and licence notices for derived assets. Do not characterize third-party research outputs as validated ASL translations without independent evidence.
